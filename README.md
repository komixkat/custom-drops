# Custom Drops

A Fabric mod that lets you customize what mobs, blocks, chests, and
fishing drop, entirely through config and presets. No datapack editing
required.

## Features

- Rewrite loot tables for mobs, blocks, chests, and fishing
- Force mob equipment (like a drowned's trident) to always drop
- Built-in presets: Cozy Survival, Better Dungeon Loot, Guaranteed Trophies
- In-game config screen via ModMenu
- Default install behaves exactly like vanilla until you change something

## Installation

Requires Fabric Loader and Fabric API. Download the jar for your
Minecraft version from the Releases page and drop it in your mods folder.

## Configuration

Open the config screen from ModMenu, or edit the JSON files directly.
Changes can be reloaded in-game without restarting.
